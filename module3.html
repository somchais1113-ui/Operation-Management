02 — Strategy
Make-to-Order vs Make-to-Stock
สองแนวทางหลักในการวางแผนการผลิต — เลือกตามลักษณะ Demand และ Lead Time ที่ยอมรับได้
📋 Make-to-Order (MTO)
ผลิตเมื่อได้รับ Order จริงเท่านั้น
WIP และ Finished Goods ต่ำมาก
Customization สูง ตรงใจลูกค้า
Lead Time ยาวกว่า MTS
ตัวอย่าง: Wendy's (ทำใหม่ตามสั่ง), Custom furniture, Engineering equipment
📦 Make-to-Stock (MTS)
ผลิตล่วงหน้าตาม Forecast
เก็บ Stock ไว้รอลูกค้า
Lead Time สั้น ส่งได้ทันที
Risk: Stock เกิน/ขาด
ตัวอย่าง: McDonald's เก่า (ทำไว้รอ), Supermarket, Electronics
🍔 Case จากบทเรียน — Fast Food Comparison:
Wendy's: MTO — ทำ Burger ใหม่ทุก Order ช้ากว่า แต่สด
McDonald's เก่า: MTS — ทำไว้รอ เร็ว แต่อาจเย็น ทิ้งเปล่า
McDonald's ใหม่: Hybrid — Cook ล่วงหน้า แต่ Assemble ตามสั่ง
Burger King: MTO (Custom) + MTS (Standard) — ยืดหยุ่นที่สุด

04 — Core Concept ⚡ สำคัญมาก
Assembly Line Balancing
การแบ่งงานใน Assembly Line ให้สมดุล — เป้าหมายคือ Maximize Efficiency และ Throughput โดยไม่มี Bottleneck
📐 สูตรที่ต้องจำ (Closed Book)
① MAX THROUGHPUT (ผลผลิตสูงสุด/วัน)
Max Production = Production Time per Day ÷ Bottleneck Task Time
② REQUIRED CYCLE TIME (เวลาต่อชิ้นที่ต้องการ)
C = Production Time per Period ÷ Required Output per Period
③ THEORETICAL MIN WORKSTATIONS (สถานีขั้นต่ำทางทฤษฎี)
Nt = Sum of All Task Times (T) ÷ Cycle Time (C) → ปัดขึ้น
④ LINE EFFICIENCY (ประสิทธิภาพสาย)
Efficiency = T ÷ (Na × C) × 100%
T = ผลรวมเวลาทุก Task  |  C = Cycle Time  |  Na = จำนวน Workstation จริง  |  Nt = ทฤษฎีขั้นต่ำ

06 — Tool ⚡ ออกสอบแน่นอน
Break-Even Analysis
เปรียบเทียบต้นทุนของแต่ละ Process Option เพื่อหาว่า Demand ระดับไหนควรใช้ Option ใด
📊 ตัวอย่างจากบทเรียน — ซื้อหรือผลิตเอง?
ผู้ผลิตต้องการ Machine Part มี 3 ทางเลือก:
Option 1: ซื้อ $200/unit (ไม่มีต้นทุนคงที่)
Option 2: ผลิตด้วย Semi-auto lathe $75/unit + Fixed $80,000
Option 3: ผลิตด้วย Machine center $15/unit + Fixed $200,000
ราคาขาย $300/unit · Demand = 1,000 units
Option 1: Buy at $200/unit
Total Cost @ 1,000 = $200,000
Total Cost = $200 × Q
@ 1,000 units = $200,000
ไม่มี Fixed Cost — เหมาะสำหรับ Volume ต่ำ
❌ ที่ 1,000 units แพงกว่า Option 2 และ 3
Option 2: Semi-auto lathe
$80,000 Fixed + $75/unit
Total Cost = $80,000 + $75 × Q
@ 1,000 units = $80,000 + $75,000 = $155,000
Break-even กับ Option 1 ที่: 80,000 = (200-75)×Q → Q = 640 units
✅ ถูกกว่า Option 1 เมื่อ Q > 640 units
Option 3: Machine center
$200,000 Fixed + $15/unit
Total Cost = $200,000 + $15 × Q
@ 1,000 units = $200,000 + $15,000 = $215,000
Break-even กับ Option 2 ที่: 80,000 + 75Q = 200,000 + 15Q → Q = 2,000 units
⚠️ คุ้มเมื่อ Q > 2,000 units — ที่ 1,000 units แพงที่สุด!

Q < 640 → Buy (Option 1)  |  640 < Q < 2,000 → Semi-auto (Option 2)  |  Q > 2,000 → Machine center (Option 3)
ที่ Q = 1,000 → Option 2 ถูกที่สุด ($155,000)
07 — Facility Design
Process Layouts
การจัดวาง Workstation และเครื่องจักร — แตะแต่ละ Layout เพื่อดูรายละเอียดและตัวอย่าง
🏗️ Job Shop Layout (Process Layout)
จัดตามประเภทเครื่องจักร — เครื่องเดียวกันอยู่ด้วยกัน
▼
JOB SHOP / BATCH
ลักษณะ: จัดกลุ่มเครื่องจักรตามประเภท เช่น Drilling ทั้งหมดอยู่ห้องเดียว Grinding อยู่ห้องเดียว

ข้อดี: Flexible — ชิ้นงานเดินทางผ่านได้หลายเส้นทาง
ข้อเสีย: ชิ้นงานเดินทางไกล ยาก Schedule

เหมาะกับ: Custom products, หลาย Product family
🏭 Cellular Layout (Group Technology)
จัดเครื่องจักรเป็น Cell ตาม Product Family
▼
CELLULAR / GROUP TECH
ลักษณะ: รวมเครื่องจักรต่างประเภทไว้ใน Cell เดียว เพื่อผลิต Product Family เดียวกัน

ข้อดี: ลด Travel distance, ลด WIP, Setup เร็วขึ้น
ข้อเสีย: ต้องลงทุน Rearrange ใหม่

วิธีสร้าง: ใช้ Part-Routing Matrix วิเคราะห์ว่า Parts ไหนใช้ Machines ไหน → จัด Groups
เหมาะกับ: Lean Manufacturing, Batch ที่ต้องการ Flexibility
🔄 Assembly Line / Flow Layout
จัดเป็นสาย ตามลำดับขั้นตอนการผลิต
▼
ASSEMBLY LINE
ลักษณะ: ชิ้นงานไหลตามลำดับ Station 1 → 2 → 3 → … จนสำเร็จ

ข้อดี: ประสิทธิภาพสูง Unit Cost ต่ำ
ข้อเสีย: ยืดหยุ่นน้อย Bottleneck ส่งผลทั้งสาย

เหมาะกับ: High-volume, Standard products เช่น รถยนต์ Electronics
08 — Technology
Computer-Integrated Manufacturing (CIM)
เทคโนโลยีที่ใช้ Computer ควบคุมการผลิต — แตะแต่ละรายการเพื่อดูรายละเอียด
🖥️
CAD
Computer-Aided Design
ออกแบบ 2D/3D บน Computer ลด Error, แก้ไขง่าย, ส่งต่อ CAM ได้เลย ตัวอย่าง: AutoCAD, SolidWorks
⚙️
CAM
Computer-Aided Manufacturing
ใช้ Design จาก CAD สั่งงานเครื่องจักรอัตโนมัติ ลดความผิดพลาดของมนุษย์ เพิ่ม Speed และ Precision
🔩
CNC Machines
Computer Numerically Controlled
เครื่องจักรที่ควบคุมด้วย Program ตัดเจาะได้ความแม่นยำสูง ทำซ้ำได้เหมือนกันทุกครั้ง
🤖
Industrial Robot
6 Degrees of Freedom
แขนกล 6 แกน (Arm sweep, Shoulder swivel, Elbow, Yaw, Pitch, Roll) ทำงานซ้ำๆ แม่นยำ ไม่เหนื่อย ใช้แทน Manual labor ที่อันตราย
🚗
AGV
Automated Guided Vehicle
รถขนวัสดุอัตโนมัติ วิ่งตาม Track/Line ที่กำหนด ลด Labor ใน Warehouse ส่วนหนึ่งของ AMH
🏗️
FMS
Flexible Manufacturing System
ระบบผลิตที่เปลี่ยน Product ได้เร็วโดยไม่ต้อง Setup ใหม่นาน ใช้ Computer Control + CNC + Robot ทำงานร่วมกัน

10 — Case Study
ฝึกวิเคราะห์ Case Module 3

🖊️ Case: โรงงานปากกาสยามวัลลา — Process Analysis

วิเคราะห์กระบวนการผลิตจริง แบบ Closed Book

โรงงานผลิตปากกาของสยามวัลลามี 5 Station:
S1: ฉีดพลาสติก — 12 units/hr  |  S2: ประกอบไส้ — 5 units/hr  |  S3: พ่นสี — 8 units/hr  |  S4: ประกอบสุดท้าย — 10 units/hr  |  S5: บรรจุ — 9 units/hr

Production time = 480 min/day · ต้องการ 200 units/day
❓ ข้อ 1: Bottleneck อยู่ที่ไหน? Throughput จริงเท่าไหร่? ▼
Bottleneck = S2 (ประกอบไส้) ช้าที่สุด = 5 units/hr
Throughput ของระบบ = 5 units/hr = 5 × 8 hr = 40 units/8hr day
หรือถ้า production time = 480 min: Cycle time ของ Bottleneck = 60/5 = 12 min/unit
Max Production = 480 ÷ 12 = 40 units/day ← ต่ำกว่าที่ต้องการมาก!
❓ ข้อ 2: คำนวณ Required Cycle Time ถ้าต้องการ 200 units/day ▼
Required Cycle Time C = Production Time ÷ Required Output
C = 480 min ÷ 200 units = 2.4 min/unit

S2 ปัจจุบัน = 12 min/unit → ช้ากว่าที่ต้องการ 5 เท่า!
ต้องเพิ่ม Capacity ของ S2 ให้ทำได้อย่างน้อย 1 unit ทุก 2.4 นาที = 25 units/hr
❓ ข้อ 3: แนะนำวิธีแก้ Bottleneck พร้อมอ้าง Theory ▼
ตาม Bottleneck Theory (Assembly Line Balancing):

① เพิ่มพนักงาน/เครื่องที่ S2: เพิ่มจาก 1 เป็น 5 คน → ทำได้ 25 units/hr (≥ 200/8hr)
② Re-balance workload: แยก Task ประกอบไส้ให้ทำพร้อมกันหลายจุด
③ ลด Cycle time S2: ใช้ Robot/Automation ช่วยประกอบ (CIM — Industrial Robot)

Process Layout: พิจารณา Cellular Layout จัดกลุ่มเครื่องจักรใหม่ลด Travel time
ผลที่คาดหวัง: Throughput เพิ่มจาก 40 → 200 units/day = เพิ่ม 400%
