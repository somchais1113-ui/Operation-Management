Master Operation Management

ศูนย์รวมบทเรียน Operation Management สำหรับทบทวนเนื้อหา วิเคราะห์กระบวนการ จัดการสต็อก วางแผนกำลังการผลิต เข้าใจ Supply Chain ฝึกคิดผ่าน Case Study และทดลองแนวคิด Lean ผ่าน Toyota Production Game

เริ่มทบทวนบทเรียน → เล่น Toyota Game ไปที่ Final Module
OM System Map จาก Demand → Process → Inventory → Quality → Improvement
Demand เข้าใจความต้องการลูกค้าและเป้าหมายของระบบ
Process วิเคราะห์ Flow, Bottleneck และประสิทธิภาพงาน
Inventory ควบคุมสต็อก EOQ และต้นทุนสินค้าคงคลัง
Lean System ลด Waste ปรับปรุงคุณภาพ และทดลองแนวคิดผ่าน Toyota Game
Core idea ทุกบทเชื่อมกันเป็นระบบเดียว: วางแผนความต้องการ → ออกแบบกระบวนการ → คุมทรัพยากร → ส่งมอบคุณภาพ → ใช้ Lean เพื่อปรับปรุงอย่างต่อเนื่อง
01
Understand the Operation เริ่มจาก Process Analysis เพื่อเห็นภาพรวมของระบบงานและปัญหาคอขวด
02
Control Resources ต่อด้วย Inventory และ Capacity เพื่อจัดการทรัพยากรให้เหมาะสม
03
Connect the Supply Chain เข้าใจการไหลของสินค้า ข้อมูล และการตัดสินใจระหว่างองค์กร
04
Practice Lean Thinking ใช้ Case Study และ Toyota Game เพื่อเข้าใจ Lean, Waste และการปรับปรุงระบบ
